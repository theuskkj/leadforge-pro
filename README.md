# LeadForge Pro

Aplicação SaaS em React + TypeScript para prospecção de empresas locais, CRM de leads, funil comercial e gerador de prompts para criação de websites.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build e testes

```bash
npm run test
npm run build
npm run lint
```

## Funcionalidades

- Dashboard com KPIs, resumo do funil e leads prioritários
- Radar de prospecção com busca mock e fallback automático para demonstração
- CRM de leads com persistência em `localStorage`
- Pipeline comercial por estágio (novo, contatado, proposta, fechado)
- Gerador de prompts para websites
- Tela detalhada de lead com histórico
- Configurações de workspace e reset de dados demo
